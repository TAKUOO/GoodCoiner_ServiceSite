# SEO Keyword Map

最終更新: 2026-06-17

## 目的

GoodCoiner サービスサイトで狙う検索語句と、それに対応するページを明確にする。
このドキュメントは `01. SEO: キーワード調査とページ別ターゲットマップを作成する` の成果物として使う。

## 前提

- GoodCoiner は `GMOコイン` ユーザー向けの `macOS デスクトップアプリ`
- 価値訴求の中心は `取引履歴の可視化` `損益分析` `トレードルール管理` `自動利確予約`
- 安全性の訴求として `APIキーを外部送信しない` `ローカル保存` が強い差別化要素

## 今は狙わないキーワード

現時点では、次の語句はページと機能が十分に一致しないため主軸にはしない。

- `ビットコイン 自動売買`
- `仮想通貨 bot`
- `FX 自動売買`
- `TradingView 連携`
- `複数取引所 一括管理`

## 実行順

1. `/` と `/usage/` のターゲット語句を固定する
2. title / description / canonical / noindex を調整する
3. sitemap / robots を整備する
4. 構造化データを追加する
5. 検索意図に沿って本文と見出しを強化する
6. 追加ランディングページを順次作る

## メモ

- 指名検索では `GoodCoiner` と `グッドコイナー` の両方を意識する
- `GMOコイン` は強い導入意図を持つので、使い方ページだけでなくトップページにも自然に含める
- `ローカル保存` `APIキーを外部送信しない` は安全性訴求として FAQ と本文の両方に入れる
